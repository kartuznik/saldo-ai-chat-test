Веб-чат с ИИ: Vite + React + TypeScript и FastAPI-прокси к OpenRouter. Контекст сдачи — тестовое Сальдо. Шапка и визуальный язык — **Кузьма**, демо дизайн-системы моего продукта.

## Запуск (5 минут)

Ключ OpenRouter кладётся только в `server/.env` (файл не коммитится). Шаблон: `server/.env.example`.

Терминал 1 — прокси:

```bash
cd server
setsid nohup .venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000 > /tmp/uvicorn.log 2>&1 < /dev/null &
curl -s http://127.0.0.1:8000/api/health
```

Терминал 2 — клиент:

```bash
cd client
npm install
ps aux | grep -E 'vite|npm run dev' | grep -v grep
setsid nohup npm run dev > /tmp/vite.log 2>&1 < /dev/null &
```

Открыть http://localhost:5173 (также работает http://127.0.0.1:5173). Адрес API без ключа: `VITE_API_BASE` (дефолт `http://127.0.0.1:8000`), шаблон `client/.env.example`. Перед `npm run dev` смотри `ps`: вторая цепочка поверх живой на 5173 маскирует, кто отвечает.

## Ключевые решения

- Скелет закоммичен в `main` как bootstrap пустого репозитория; весь дальнейший код — в `feat/chat`, в `main` только через PR.
- FastAPI: ASGI, CORS и `StreamingResponse` из коробки, без отдельного SSE-сервера и без синхронного WSGI.
- httpx.AsyncClient: долгий SSE-read (до 60s) не блокирует event loop; один клиент в lifespan, без сокета на каждый запрос.
- В апстрим уходят последние 30 сообщений: у free-моделей узкое окно контекста, длинная история даёт 400/413.
- Ошибки апстрима до старта SSE отдаём JSON (429/504/502). После старта стрима HTTP-статус уже 200 — только ERROR в лог и закрытие потока.
- Отмена апстрима: обрыв клиента даёт `CancelledError` или `request.is_disconnected()`; генератор логирует строку и в `finally` делает `aclose()` httpx-стрима — отдельную задачу не создаём.
- модель liquid/lfm-2.5-2.6b:free выбрана живой проверкой 200, потому что meta-llama/llama-3.2-3b-instruct:free отключён от free-варианта (404 апстрима).
- CORS разрешает оба origin (`http://localhost:5173` и `http://127.0.0.1:5173`), потому что пользователь может открыть либо; прокси не проверяет origin-строгость, только whitelist.
- История в `localStorage`: ожидаемый UX чата (пережил перезагрузку) против приватности на общем компьютере; явный сброс — кнопка «Очистить историю».
- `VITE_API_BASE` — только адрес прокси, не ключ. Ключ живёт в `server/.env` и на клиент не попадает.
- Стандартный `outline` убран, вместо него единый `:focus-visible` (`2px solid var(--accent)`, offset 2px): WCAG 2.4.7 требует видимый фокус, но не требует браузерный outline; свой индикатор совпадает с акцентом Кузьмы и не рисуется на pointer-клике.
- Полозок ленты полупрозрачный accent на прозрачном треке: видно, где ты в истории, без яркой полосы на тёмном фоне.
- Разработка на VPS 2 GB потребовала временно остановить контейнеры мониторинга (память 92%), подняты после сдачи.
- Бренд: h1 и шапка — «Кузьма»; чат — визуальное демо дизайн-системы моего продукта; контекст сдачи — тестовое Сальдо. Аватар владельца — силуэт голова+плечи в палитре Кузьмы, не серый PNG и не фото.
- Тёмная тема по умолчанию — позиция, не недоделка: макет Кузьмы тёмный, светлая тема сознательно на полке.
- Markdown в ответах ассистента: `marked` + DOMPurify. Снято с полки, потому что без санитайзера сырые `*` и заголовки ломают читаемость, а без DOMPurify HTML из модели — XSS. Пользовательский текст по-прежнему сырой.
- Сайдбар и экраны «Канал / Генерация / Посты / Память / Настройки» из макета не переносятся: нерабочая продуктовая навигация в тестовом артефакте есть фейковый UI. Заимствуем визуальный язык, не продуктовую структуру.

### Симуляции обрыва

Методология, чтобы не путать «процесс умер» и «клиент отвалился»:

- **SIGTERM** (`kill <pid>` uvicorn, без `-9`): процесс дренирует — в логе `Shutting down` / `Waiting for application shutdown` / `Finished server process`. Уже открытый стрим закрывается штатно.
- **SIGKILL** (`kill -9`): рвёт сокет сразу, без graceful. UI видит обрыв сети или `interrupted`.
- **DevTools Offline**: рвёт *новые* `POST /api/chat` (карточка «сеть оборвалась», «Повторить» шлёт payload без обрывка assistant). Уже установленный SSE так не режется — Offline не абортит открытый fetch.
- **Наблюдение владельца** (ночь 23→24.09): `pkill`/kill mid-stream — шероховатость UI; зафиксировано в черновике приёмки, не пряталось.
- **Стоп на окне TTFB**: AbortController до первого токена. В `/tmp/uvicorn_2409.log` строка `upstream cancelled: client disconnected`. TTFB ~4 с — очередь free-модели, не баг прокси: заголовки ответа и первый `data:` приходят почти вместе.

### История дефекта лейаута

- Композер и «Стоп» уезжали под складку: `min-height` раздувал страницу. Фикс: lock `100dvh` + `overflow: hidden` на `html/body/#root` (`b9993ab`).
- Пустой пузырь ассистента до первого токена. Фикс: не создавать assistant до дельты (`4c57d36`), индикатор печати снаружи `.log` (`50005da`), восстановление слетевшего `export default` (`9f7d331`).
- Лента насильно скроллилась во время чтения. Фикс: sticky follow с порогом 40px и кнопкой «↓ к новому» (`694a056`).
- Полозок ленты — тихий accent (`33af05d`).
